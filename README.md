# MIGHTX7

## About

MIGHTX7 is a Web3 project developed by CHIKARA CO., LTD. in Japan.

The project focuses on sustainable fish resource recycling and the development of industrial technology for processing fish processing waste into fish meal and fish oil.

MIGHTX7 combines blockchain technology with a real-world industrial recycling initiative.

## Blockchain

- Network: BNB Smart Chain
- Standard: BEP-20
- Token: MIGHTX7
- Total Supply: 1,000,000,000 MIGHTX7
- Contract: 0xc02B3EE1237e4bF485bE9D1dA12e815fcDa54687

## Project

The planned industrial project aims to process fish processing waste and convert it into useful products such as fish meal and fish oil.

Planned processing capacity: up to 50 tons per day.
